# 数据字典

命名遵循客户数仓规范：表名为“分层_业务域_实体名_粒度”，代码中使用“库.表”；字段为 snake_case 的“实体_属性”，后缀关键字 `_code/_no/_name/_type/_status/_date/_time/_amt/_qty/_rate`；类型/状态/等级字段统一编码，并在注释中写明每个取值的含义；所有表按 `travel_date`（YYYYMMDD）分区。建表语句见 `docs/ddl/`。

来源标记：**真实**=携程采集原值；**解析**=由真实文本规则解析；**推断**=由真实数据推断；**派生**=基于真实值按业务规则计算；**仿真**=按业务逻辑统计仿真生成（非真实交易）。
